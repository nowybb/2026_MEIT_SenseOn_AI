# SenseOn AI: 청각장애인을 위한 후방 접근 위험 감지 시스템

---

## 프로젝트 배경

- 보행 중에는 차량, 오토바이, 자전거 등 주변 이동체의 접근을 빠르게 인지하는 것이 중요하다.
- 특히 사용자의 후방에서 접근하는 이동체는 시야만으로 즉시 확인하기 어렵고, 청각 정보 활용이 제한되는 경우 접근 상황을 인지하는 데 어려움이 발생할 수 있다.
- 단순히 후방에 객체가 존재한다는 사실만으로 경고할 경우 불필요한 경고가 반복될 수 있다.
  - 정지해 있는 차량
  - 사용자에게서 멀어지는 객체
  - 사용자의 측면을 지나가는 객체
  - 실제 이동 경로와 겹치지 않는 객체
- 따라서 객체의 존재 여부뿐만 아니라 **접근 여부, 이동 방향, 예상 이동 경로, 충돌 가능성 등을 종합적으로 판단하는 시스템**이 필요하다.

---

## 프로젝트 목적

SenseOn AI는 후방 카메라 영상을 기반으로 차량, 자전거, 오토바이 등의 이동 객체를 인식하고, 객체의 움직임을 분석하여 사용자에게 접근하는 위험 객체를 판단하는 시스템이다.

객체 탐지 및 추적 결과에서 얻은 위치 정보를 시간에 따라 분석하여 객체의 접근 여부와 이동 방향을 판단하고, 예상 이동 경로와 사용자의 위험 영역이 겹치는지를 분석한다.

최종적으로 위험도를 `SAFE`, `CAUTION`, `DANGER` 단계로 구분하고 여러 객체가 존재할 경우 가장 위험한 객체를 우선 경고 대상으로 선정하는 것을 목표로 한다.

### 시스템 목표

- 후방 이동 객체 인식
- 동일 객체의 지속적인 추적
- 사용자 방향 접근 여부 판단
- 객체 이동 방향 및 예상 경로 계산
- 사용자와의 충돌 가능 경로 판단
- Visual TTC 기반 접근 위험도 추정
- 위험 단계 분류
- 다중 객체 중 주요 위험 객체 선정
- 향후 웨어러블 장치와 연동하여 위험 정보 전달

# 프로젝트 설명

## 전체 시스템 구조

SenseOn AI는 크게 **객체 인식·추적 영역(AI1)**과 **위험 판단 영역(AI2)**으로 구성한다.

AI1에서는 후방 카메라 영상에서 이동 객체를 탐지하고 동일 객체를 지속적으로 추적한다.

AI2에서는 AI1에서 전달받은 객체의 위치 및 크기 변화를 시간에 따라 분석하여 접근 여부, 이동 방향, 예상 경로, 충돌 가능성 등을 계산하고 최종 위험도를 결정한다.

현재 AI2 위험 판단 알고리즘의 1차 프로토타입을 구현했으며, 실제 객체 탐지 결과가 준비되기 전까지 Mock Data를 활용하여 기능을 검증하고 있다.

---

## 전체 처리 흐름

```text
후방 카메라 영상
        ↓
객체 탐지 (YOLO)
        ↓
객체 추적 (BoT-SORT)
        ↓
객체별 위치 정보
track_id / bbox / center / timestamp
        ↓
객체 이동 이력 관리
        ↓
접근 여부 판단
        ↓
이동 방향 및 미래 위치 예측
        ↓
충돌 가능 경로 판단
        ↓
Visual TTC 추정
        ↓
SAFE / CAUTION / DANGER
        ↓
Primary Hazard 선정
        ↓
웨어러블 경고 시스템 연동
```

# AI1: 객체 탐지 및 추적

AI1은 후방 카메라 영상에서 위험 판단에 필요한 이동 객체를 인식하고, 프레임이 변경되어도 동일 객체를 지속적으로 추적하는 역할을 담당한다.

객체 탐지에는 YOLO 계열 모델을 활용하고, 객체 추적에는 BoT-SORT를 활용하는 구조를 목표로 한다.

### 주요 탐지 대상

| 객체 | 용도 |
|---|---|
| car | 후방 접근 차량 감지 |
| bicycle | 후방 접근 자전거 감지 |
| motorcycle | 후방 접근 오토바이 감지 |

---

## AI1 → AI2 전달 데이터

AI2는 영상 자체를 직접 분석하기보다 AI1에서 탐지·추적한 객체 정보를 입력으로 사용한다.

```python
{
    "track_id": 10,
    "class_name": "car",
    "confidence": 0.95,
    "timestamp": 0.2,
    "bbox": [280, 180, 405, 350],
    "center_x": 342.5,
    "center_y": 265.0
}
```

| 데이터 | 설명 |
|---|---|
| track_id | 추적 중인 객체의 고유 번호 |
| class_name | 객체 종류 |
| confidence | 객체 탐지 신뢰도 |
| timestamp | 해당 객체가 탐지된 시간 |
| bbox | 화면에서 객체가 차지하는 영역 |
| center_x | 객체 중심의 가로 위치 |
| center_y | 객체 중심의 세로 위치 |

# AI2: 위험 판단 알고리즘

AI2는 AI1에서 전달받은 객체 정보를 시간에 따라 분석하여 **실제로 사용자에게 위험하게 접근하고 있는 객체인지 판단하는 역할**을 담당한다.

단순히 객체가 탐지되었다는 이유로 경고하지 않고 객체의 접근 여부와 이동 경로를 함께 고려한다.

---

## 1. 객체별 이동 이력 관리

동일한 `track_id`를 가진 객체의 탐지 결과를 시간 순서대로 저장한다.

```text
Track ID 10

Frame 1 → 위치 / 크기
Frame 2 → 위치 / 크기
Frame 3 → 위치 / 크기
        ↓
객체의 시간에 따른 변화 분석
```

이를 통해 현재 위치만 확인하는 것이 아니라 객체가 **어디에서 어디로 이동하고 있는지** 분석할 수 있다.

---

## 2. 접근 여부 판단

후방 객체가 사용자에게 접근하면 일반적으로 영상에서 객체가 차지하는 크기가 증가한다.

AI2는 시간에 따른 bounding box 크기 변화를 이용하여 객체의 접근 정도를 계산한다.

```text
객체 크기 증가
      ↓
Approach Rate 계산
      ↓
기준값 초과
      ↓
Approaching = True
```

반대로 객체 크기가 유지되거나 감소하는 경우 접근 객체로 판단하지 않는다.

---

## 3. 이동 방향 및 미래 위치 예측

객체의 이전 위치와 현재 위치를 비교하여 화면상 이동 속도를 계산한다.

```text
이전 위치
   ↓
현재 위치
   ↓
이동 방향 및 속도 계산
   ↓
일정 시간 후 예상 위치 계산
```

이를 통해 단순히 가까워지고 있는지만 판단하는 것이 아니라 **객체가 어느 방향으로 이동하고 있는지** 함께 분석한다.

---

## 4. Collision Zone 및 충돌 경로 판단

사용자 후방에서 실제 위험으로 이어질 가능성이 높은 영역을 `Collision Zone`으로 정의한다.

객체의 현재 위치와 예상 위치를 연결한 이동 경로가 Collision Zone과 겹치는지 확인한다.

```text
객체 접근
   ↓
예상 이동 경로
   ↓
Collision Zone과 교차?
   ↓
Path Collision = True / False
```

따라서 사용자에게 접근하더라도 측면으로 지나가는 객체와 사용자 방향으로 접근하는 객체를 구분할 수 있도록 설계하였다.

> 현재 Collision Zone 범위는 초기 개발값이며 실제 후방 카메라 영상 데이터를 확보한 후 조정할 예정이다.

---

## 5. Visual TTC 추정

객체의 화면상 크기 변화를 이용하여 `Visual TTC(Time To Collision)`를 추정한다.

```text
객체 크기 변화
      ↓
화면상 확대 속도 계산
      ↓
Visual TTC 추정
```

Visual TTC 값이 작을수록 빠르게 가까워지고 있는 객체로 해석한다.

> 현재 Visual TTC는 실제 거리 센서를 이용한 물리적 충돌 시간 측정값이 아니라 영상에서 관찰되는 객체 크기 변화를 이용한 시각적 추정값이다.

---

## 6. 위험 단계 판단

접근 여부, 충돌 가능 경로, Visual TTC를 종합하여 위험 단계를 결정한다.

| 위험 단계 | 의미 |
|---|---|
| SAFE | 현재 경고가 필요하지 않은 상태 |
| CAUTION | 접근 및 경로상 위험 가능성이 있어 주의가 필요한 상태 |
| DANGER | 충돌 가능성이 높고 빠르게 접근하는 상태 |

현재 위험 판단의 기본 흐름은 다음과 같다.

```text
객체 접근 여부
      ↓
충돌 가능 경로 여부
      ↓
Visual TTC
      ↓
SAFE / CAUTION / DANGER
```

> 현재 TTC 기준값은 초기 프로토타입 검증을 위한 값이며 실제 영상 데이터 기반 테스트를 통해 조정할 예정이다.

---

## 7. Primary Hazard 선정

후방에는 하나의 객체만 존재하지 않을 수 있다.

여러 객체가 동시에 탐지되는 경우 각 객체의 위험도를 비교하여 **가장 우선적으로 경고해야 하는 객체를 Primary Hazard로 선정한다.**

```text
자동차      → DANGER
자전거      → SAFE
오토바이    → CAUTION

        ↓

Primary Hazard
        ↓
자동차
```

이를 통해 여러 객체가 존재하는 상황에서도 가장 중요한 위험 정보를 우선적으로 전달할 수 있도록 한다.

# 데이터 확보 및 검증 계획

실제 환경에서의 성능을 검증하기 위해 후방 카메라 영상 데이터를 단계적으로 확보한다.

### 1차 데이터

통제된 환경에서 다음과 같은 기본 상황을 촬영한다.

- 객체 없음
- 정지 객체
- 후방 접근
- 멀어지는 객체
- 측면 통과
- 사용자 방향 접근
- 다중 객체
- 카메라 흔들림
- 객체 일부 가림

초기에는 약 **30~50개의 짧은 영상 클립**을 확보하여 AI1과 AI2의 전체 처리 흐름을 검증한다.

### 2차 데이터

기본 기능 검증 이후 실제 사용 환경의 다양성을 추가한다.

```text
객체
car / bicycle / motorcycle / e-scooter

환경
도로 / 골목 / 자전거도로 / 보행 공간

조명
낮 / 흐림 / 해질녘 / 야간

행동
정지 / 접근 / 멀어짐 / 측면 통과

영상 조건
정상 / 흔들림 / 부분 가림 / 원거리
```

실제 데이터에서는 Ground Truth를 함께 구축하여 시스템 판단 결과와 비교한다.

## 최종 목표

SenseOn AI의 최종 목표는 단순한 객체 탐지를 넘어,

**“무엇이 뒤에 있는가?”가 아니라  
“무엇이 실제로 나에게 위험하게 접근하고 있는가?”**

를 판단하여 사용자에게 필요한 위험 정보만 빠르게 전달하는 후방 안전 보조 시스템을 구현하는 것이다.
